How to get your HoYoLAB cookie

Copy two cookie values from your signed-in HoYoLAB browser session.

  1. Open HoYoLAB Account Center in Chrome or Edge and sign in.
  2. Open Developer Tools with ⌥ + ⌘ + I on Mac, or F12 on Windows.
  3. Open Application → Storage → Cookies → https://www.hoyolab.com.
  4. Find ltoken_v2. Copy only its Value and paste it into HoYoLAB token value below.
  5. Find ltuid_v2. Copy only its Value and paste it into HoYoLAB account ID value.
  6. Select Save and sync. The tracker adds the cookie names and formatting for you.

The account ID comes from the ltuid_v2 cookie; it is different from your in-game UID.

SKPORT

Arknights: Endfield

How to get your SKPORT account token

Copy the account token from your signed-in SKPORT session.

  1. Open SKPORT’s Endfield portal and sign in with the Gryphline account linked to Endfield.
  2. In the same browser and profile, open SKPORT’s account-token page.
  3. Copy the full JSON response, or just its data.content value.
  4. Paste it into the SKPORT account token field, then select Save and sync.

If the page shows an error or an empty result, sign in again at the Endfield portal using the same browser profile, then reload the token page.
